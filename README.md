# Hecate
### The magic function library thing
This project is currently under development, please check back later for more progress
### About
Hecate is a vtable implementation with the goal of being as user friendly as possible. 

### Roadmap
- [x] vtables
- [ ] one-line member method calls
- [ ] helper macros for defining classes

### Building
to build the current sample project, just run `make` from the build folder.
